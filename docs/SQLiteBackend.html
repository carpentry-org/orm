SQLiteBackend

is the SQLite backend for the ORM.

Loading this file pulls in the ORM core and the carpentry-org/sqlite3 package, then registers the dynamic helpers that derive-model uses to emit SQL and row marshalling.

(load "git@github.com:carpentry-org/orm@0.5.0" "backends/sqlite3.carp")

(deftype Item [id Int text String done Bool])
(derive-model Item SQLiteBackend [id Int])

Generated functions take an &SQLite3.SQLite as their first argument. Supported field types are Int, Long, Double, Float, String, and Bool, plus (Maybe T) of any of those for a nullable column. Anything else raises a macro error at expansion time.
