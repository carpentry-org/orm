SQLiteBackend

is the SQLite backend for the ORM.

Usage

(load "orm/backends/sqlite3.carp")

(deftype Item [id Int text String done Bool])
(derive-model Item SQLiteBackend [id Int])

(let [db (Result.unsafe-from-success (SQLite3.open "app.db"))]
  (Item.create-table &db)
  (Item.insert &db &(Item.init 0 @"hi" false)))

All generated functions take an &SQLite3.SQLite as their first argument.

Supported types

Int, Long, Double, Float, String, Bool. Unknown types raise a macro error at expansion time.
